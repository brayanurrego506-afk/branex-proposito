# Branex — Propósito Organizacional
> Presentación web interactiva del propósito de Branex S.A.S

## Deploy rápido en Vercel

### Opción 1 — GitHub + Vercel (recomendado)
```bash
git init
git add .
git commit -m "feat: branex proposito web"
git remote add origin https://github.com/TU_USUARIO/branex-proposito.git
git push -u origin main
```
Luego en vercel.com → Import → selecciona el repo → Deploy.

### Opción 2 — Local
```bash
npm install
npm run dev
```
Abre http://localhost:5173

### Opción 3 — Vercel CLI
```bash
npm install -g vercel
npm install
vercel
```

## Navegación
- **Teclado:** ← → para ir entre slides
- **Mouse:** botón "Siguiente" o puntos del lado derecho
- **Touch/Móvil:** swipe izquierda/derecha
